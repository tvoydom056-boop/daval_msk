# Только для Claude

Общие правила для всех ИИ и для команды - в AGENTS.md выше. Здесь то, что касается только Claude Code.

- **Ассистент и Codex.** На машине Виталия Claude ставит задачу и принимает результат, тяжёлую механику (массовые генерации фото, сборку отчёта, рутинный код) может делать Codex по заданию. Задания для Codex писать по образцу `codex/TASK_images.md` и `codex/TASK_report.md`: главное правило (задание - единственный источник, ничего не удалять, без платных сервисов), цель, источники, ожидаемые файлы, проверка перед сдачей, короткая сдача.
- **Просмотр макетов.** В сессиях Claude у Виталия есть конфигурация сервера `memorial-sites` (порт 8765) для встроенного браузера. Если её нет, запускать сервер командой из AGENTS.md.
- **Цены и названия** Claude только предлагает, решают вдвоём (PLAN.md раздел 10). Не менять цены в макетах без задачи.
- **Личные пути** с машины Виталия (абсолютные пути к его дискам и папкам) в общие файлы репозитория не добавлять: у второго участника их нет. Пути в документах - только относительно корня репозитория.
