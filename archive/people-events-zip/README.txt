Povod: 50 generated photographs

Open assets/collections/people-events-50/README.md for the collection, prompts, references and five contact sheets. All people are fictional. Generation used built-in image_gen.

From this extracted folder, with Python 3.9+ and Pillow installed:
python codex/prepare_people_events_pack.py --check
python codex/prepare_people_events_pack.py --prepare
