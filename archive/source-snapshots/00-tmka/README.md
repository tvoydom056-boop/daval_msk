# daval_msk - «Летопись» и «Повод»

Два сайта под ключ (названия рабочие):

- **Летопись** (`letopis/`) - страницы памяти о близких: история жизни по главам, реставрация и цвет старых фото, голос и видео, семейное древо, QR-код на памятник, место захоронения.
- **Повод** (`v3/povod/`, прежняя статика в `povod/`) - сайты-подарки: главная с выбором повода и отдельные страницы свадьбы, дня рождения, годовщины и юбилея с полным примером подарка.

Сейчас это **макеты**: исходная статика на HTML/CSS/JS и отдельные прототипы в `v3/`. Актуальный «Повод» находится в `v3/povod/`: обычная прокрутка, открытый выбор повода, полный пример в `details` и демо-форма. Подробности в [его README](v3/povod/README.md).

## Актуальный «Повод»

Из `v3/povod/`: `npm ci`, затем `npm run dev`. Открыть http://127.0.0.1:5174/. Сборка: `npm run build`; просмотр сборки: `npm run preview`, http://127.0.0.1:4174/. Браузерная проверка: `codex/v3/check_povod_clear.mjs`, инструкции в README прототипа.

Выпускная проверка: 293/293 PASS, 22 варианта страницы, 56 снимков, без ошибок консоли и ресурсов. Taste Skill 2.5.1 уже был установлен и использован без переустановки. Формальные исключения Taste и результаты производительности описаны в [состоянии редизайна](codex/v3/POVOD_CLEAR_STATE.md); формальный Taste PASS не заявляется. Публикация не выполнялась, форма остаётся демонстрационной.

`build_artifacts.py` собирает только прежние статические версии. PDF из `report/` не пересобран и текущий интерфейс v3 не покрывает.

## Как открыть прежние статические макеты

```
python -m http.server 8765
```

Затем http://localhost:8765/letopis/ и http://localhost:8765/povod/ . Можно открыть index.html и двойным кликом, но с сервером надёжнее.

Кнопка «Слоты медиа» в правом нижнем углу подписывает каждое место под фото или видео: что туда поставить, формат и длительность.

## Где что

| Путь | Что |
|---|---|
| `PLAN.md` | Общий план: продукты, цены, бюджет 50 000 ₽, роли, этапы, что решить |
| `HANDOFF.md` | Текущее состояние и следующие шаги |
| `v3/povod/` | Актуальный прототип «Повода» на Vite, содержимое в `src/data.js` |
| `report/` | PDF-отчёт для команды |
| `letopis/index.html`, `styles.css`, `app.js` | Макет «Летописи», древо и интерактив в `app.js` |
| `povod/data.js` | Тексты, цены и примеры прежней статики |
| `povod/app.js` | Вёрстка лендингов поводов из `data.js` и интерактив |
| `povod/*.html` | Главная и страницы поводов (оболочки, содержимое из `data.js`) |
| `*/assets/img/` | Фото для макетов (сгенерированы, люди вымышленные) |
| `build_artifacts.py` | Сборка одностраничных версий для показа ссылкой |
| `codex/` | Задания, по которым генерировались фото и отчёт |
