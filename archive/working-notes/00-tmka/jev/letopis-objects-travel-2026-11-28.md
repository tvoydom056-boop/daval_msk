## matrix

Требования: сделать ещё 50 разных визуальных заготовок; включить предметы, альбомы, закладки и небольшие фишки.

Операция: составить 50 записей в chunks/ с непересекающимися id, объединить в manifest.json и кратко описать концепции в CONCEPTS.md. Старый manifest используется только для сравнения сюжетов. В новом у каждой записи id, slug, title, category, theme, concept, application, suggested_slot, aspect_ratio, period, generation_prompt, transparent_background, file и status. Для новых декоративных применений слот обозначается как предлагаемый. Современная стилизация не выдаётся за подлинный архив. Все люди и персональные истории вымышлены; никаких читаемых персональных данных, логотипов и водяных знаков.

Проверка: ровно 50 новых уникальных id 51-100; пять групп по 10; уникальны пути, полные промпты и конкретные сюжеты. Таблица сравнения фиксирует различие от прежней серии.

## generation

Требования: выполнить работу по плану; включить предметы и людей в путешествиях, походах и поездках.

Операция: отдельный вызов встроенного imagegen на каждый id. 51-60 - разные формы альбомов; 61-70 - отдельные предметные вырезки с transparent_background=true; 71-80 - дорожные вещи; 81-90 - новые действия людей в дороге; 91-100 - места и атмосфера. Для кадров с фоном параметр false. Копировать оригиналы в generated/ сразу после получения, оставляя исходники генератора. Не подменять серию коллажем и не переходить к API/CLI без отдельного запроса. Исполнители работают по непересекающимся диапазонам и пишут отдельные журналы, общий manifest объединяет ведущий.

Проверка: каждый оригинал открыть и посмотреть; оценить соответствие сюжету, материал, лица/руки, лишний текст, артефакты и эпоху. У 61-70 проверить настоящий альфа-канал и прозрачные пиксели; нарисованная шахматка и белый прямоугольник результатом не считаются. Ошибки исправлять адресно встроенным генератором. Записать фактический итог для каждого id.
