Готовая библиотека из 50 демонстрационных фотографий с вымышленными людьми для сайта-подарка. Все кадры созданы встроенным image_gen, просмотрены и имеют статус accepted. Каждая фотография самостоятельна.

## Подготовка и проверка

Из корня проекта:

```powershell
python codex/prepare_people_events_pack.py
python codex/prepare_people_events_pack.py --check
```

Нужны Python 3.9+ и Pillow. Подготовка создаёт производные, а --check проверяет набор только на чтение. Нативные оригиналы сохранены без растяжения и увеличения разрешения. В каталоге записаны фактические размеры, SHA-256, относительные пути, полные использованные промпты и индивидуальные результаты визуальной проверки.

## Границы задачи

Набор не подключён к страницам сайта и не меняет маршруты. Не переносите все 50 файлов в v3/povod/public/media/img/: текущий pipeline сайта ожидает ровно 12 JPEG и четыре карточки поводов. Подключение отобранных изображений - отдельная задача. Существующие подборки не перезаписываются. В каталоге используются только относительные пути; приватных ссылок и реальных клиентских данных здесь нет.
