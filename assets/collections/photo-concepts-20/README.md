# 20 новых фотоконцепций для «Повода»

Это отдельный набор из 20 новых событий, дополняющий people-events-50. У каждого кадра свой уникальный theme, действие и локация. Темы: выпуск, своё жильё, работа, первые достижения, творчество и совместные проекты. Для первой выставки используется распаковка абстрактной картины, а не сбор яблок.

Все 20 фотографий созданы встроенным image_gen, люди вымышленные. В каталоге сохранены фактически использованные промпты, метаданные и индивидуальные визуальные проверки. Новые темы не подключаются к маршрутам сайта.

## Файлы и подготовка

- catalog.json: 20 принятых изображений pc001-pc020, фактические размеры, SHA-256 и результаты просмотра.
- prompts.md: полные английские промпты принятых изображений, включая уточнения композиции и исправления.
- references.md: стилистические источники и честные статусы проверки.
- 20 нативных PNG, 20 JPEG-превью, 20 WebP-превью и два обзорных листа по десять кадров.

Из корня проекта:

```powershell
python codex/prepare_people_events_pack.py --profile photo-concepts-20 --prepare
python codex/prepare_people_events_pack.py --profile photo-concepts-20 --check
```

Нужны Python 3.9+ и Pillow. Первый режим готовит производные; --check работает на чтение. Оригиналы сохранены без растяжения и увеличения разрешения. Все технические поля и фактический статус приёмки заполнены. Старый профиль people-events-50 остаётся по умолчанию и проверяется прежней командой без --profile.

## Приёмка

Для повторной приёмки требуются ровно 20 уникальных ID и 20 разных theme, квоты 14/6 и 8/8/4, читаемые файлы и отсутствие одинаковых SHA-256. Техническая проверка дополняет просмотр лиц, пальцев, взаимодействий с предметами, поддержки младенца, баланса ребёнка и сохранности главного действия в обрезках. Низ должен оставаться обычной непрерывной фотографией без fade, gradient или искусственной полосы для подписи.

Референсы относятся только к фотографическим приёмам. Не выдавать их за подтверждение содержания нового события или за просмотренные входные картинки. Существующие библиотеки и интерфейс сайта не изменяются.
