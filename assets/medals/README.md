# Библиотека медалей

50 отдельных PNG-референсов реально существовавших медалей СССР для страниц «Летописи» и генерации композиций. Изображения сгенерированы по музейным и справочным образцам; у каждого сохранены название, год, источник и промпт.

## Структура

```text
assets/medals/
  png/           50 изображений с прозрачным фоном
  catalog.json   каталог и сведения о каждом изображении
  prompts.txt    промпты imagegen
  sources.txt    источники, авторство и лицензии исходных фотографий
  README.md      устройство библиотеки и правила добавления
```

## Переиспользование

- Для новой генерации прикрепите нужные PNG из `png/` и опишите композицию. В `prompts.txt` сохранены исходные инструкции; общий промпт для сохранения внешнего вида есть в поле `reuse_prompt` каталога.
- Для сайта выбирайте запись по стабильному `id`, например `m001`. Поле `file` содержит путь относительно этой папки: `png/01-za-trudovuyu-doblest.png`. Поле `name` подходит для подписи, `width` и `height` задают исходные размеры.
- При подготовке страницы используйте выбранные изображения. Полный набор остается в этой общей библиотеке.
- Сведения об авторах и лицензиях исходных фотографий находятся в `sources.txt` и полях `reference_*` каталога.

## Добавление медали

1. Проверьте реальное название и найдите образец с источником.
2. Сохраните полный лицевой вид с колодкой в PNG с прозрачным фоном. Имя файла - номер и название латиницей через дефис.
3. Добавьте запись в `catalog.json`: новый уникальный `id`, путь `file`, название, год, категорию, размеры, контрольную сумму SHA-256, источник и промпт. Обновите `count`.
4. Дополните `prompts.txt` и `sources.txt`, проверьте изображение и путь из каталога.

Существующие ID и имена файлов сохраняются при переиспользовании. Следующий свободный ID - `m051`.

## Git

В репозиторий добавляется вся папка `assets/medals/`: PNG, каталог и документация. В ней нет зависимости от локального кэша генератора или отдельного рабочего дерева Git.

Архив для скачивания хранится отдельно в `output/medals-50/`, эта папка исключена из Git. Для передачи через Git используются отдельные файлы библиотеки.
