# Фотографии для двух макетов сайтов
Цель: 15 фотореалистичных кадров для макетов двух сайтов. Сайт «Летопись» - страницы памяти об умерших близких и семейное древо. Сайт «Повод» - сайты-подарки к свадьбе, дню рождения, годовщине, юбилею. Кадры должны выглядеть как настоящие фотографии (плёнка, телефон, живой свет), а не как глянцевый ИИ-рендер. Все люди вымышленные, лица задавать только демографией (возраст, пол, типаж), без сходства со знаменитостями. Россия, обычные люди, без надписей, логотипов и водяных знаков в кадре.
