# «Летопись» v3, проба: герой + глава Петра как фильм, управляемый прокруткой
Цель: один отрезок сайта уровня студий awwwards 2026: экран закреплён, прокрутка ведёт раскадровку - камера наезжает, слои движутся на разной глубине, предметы живут в сцене, текст раскрывается по мере прокрутки. Никаких «блоков, которые просто выплывают и стоят». Проба показывается заказчику; если понравится, подход переносится на весь сайт.

## Стек и где работать
- Папка: E:/CLAUDE/Сайты памяти и поздравлений/v3/letopis/ (создать). Vite (vanilla JS, без фреймворка), gsap (ScrollTrigger), lenis. Установка: npm install с кэшем на D: (npm_config_cache=D:/CLAUDE_Apps/npm-cache), node_modules в папке проекта. Скрипты npm: dev, build (base './', чтобы dist открывался из любой папки), preview.
- Медиа взять копиями из letopis/assets/v2 (people/petr.jpg, props/medal.png, letter.png, warphoto.png, pilotka.png, scenes/hero.jpg, war.jpg, fog.jpg, video/hero.mp4, war.mp4, fog.mp4) в v3/letopis/public/media/. Новое: сгенерируй встроенной генерацией лист развёрнутого фронтового письма - пожелтевшая бумага в линейку с сгибами треугольника, края потёрты, БЕЗ текста (текст наложим сами), 1600x2000 -> public/media/letter-open.jpg.
- Шрифт один: Literata (300-700 + курсив), локально через @fontsource/literata или Google Fonts.

## Общее
- Lenis: lerp 0.085, синхронизация с ScrollTrigger (lenis.on('scroll', ScrollTrigger.update), gsap.ticker). Плёночное зерно поверх всего (canvas-шум 2-3% на 24 к/с), мягкая виньетка.
- Типографика с сильным контрастом масштабов: крупное - clamp(96px, 15vw, 260px), Literata 300, межбуквенный -0.03em; мелкое - 11-12 px капителью с разрядкой .22em. Тексты подписей 18-22 px, не 14.
- Навигация не плашкой: тонкая строка текста 11 px капителью вверху, mix-blend-mode difference, слева «Летопись», справа «Древо · Истории · Цены».
- Все анимации на transform/opacity/clip-path/filter, 60 к/с. prefers-reduced-motion: без закрепления и scrub, сцены по порядку статично.
- 375 px: та же раскадровка, позиции и размеры подогнаны (сделай отдельные значения), ничего не обрезано и не перекрыто.

## Сцена 0. Герой (закрепление на 160vh, scrub 1)
- Загрузка (не прокрутка): видео hero на весь экран, масштаб 1.18 -> 1.0 за 2,4 с (expo.out); слово «Летопись» огромное, буквы поднимаются из маски по одной (шаг 0,045 с), под ним курсивом «рода» со сдвигом вправо на 1/3 ширины слова; через 0,8 с строка «Истории тех, благодаря кому мы есть» и тонкая подпись «Листайте» с медленно бегущей вниз линией 1 px.
- Прокрутка 0 -> 100%: видео 1.0 -> 1.14 и чуть вверх (-6vh); заголовок уходит вверх (-28vh) и в прозрачность с размытием 0 -> 8 px; слой тумана fog.mp4 (screen) поднимается снизу и к 85% закрывает весь экран светлой дымкой; к 100% дымка темнеет в чёрный - из него начинается глава.

## Сцена 1. Глава Петра (закрепление на 620vh, одна timeline со scrub 1.2, метки по % прогресса)
1. 0-12%. Чёрный экран. В центре огромные цифры года, только контур 1 px цветом #c9894a (-webkit-text-stroke), высота около 38vh. Прокрутка перебирает год 1909 -> 1941 (числа меняются по кадрам, с лёгким вертикальным «барабаном» у каждой цифры). Над цифрами мелко: «Глава первая · Пётр Соколов · 1909-1943».
2. 12-30%. Видео war раскрывается вертикальной щелью от центра (clip-path inset(0 50% 0 50%) -> inset(0)), камера наезжает 1.28 -> 1.06, туман-слой fog (screen, .55) на переднем плане медленно плывёт в противоход (-4vw). Цифры «1941» уезжают влево и становятся полупрозрачной заливкой (opacity .18, mix-blend overlay) поверх поля. Слева снизу подпись: строки поднимаются из маски по одной (по прокрутке): «1941. Ушёл на фронт в июле.» / «Дома остались Мария и двое сыновей.» / «Николаю было десять.» - последняя строка курсивом акцентом.
3. 30-48%. Фотокарточка (warphoto.png, примерно 26vw по ширине) влетает снизу справа в 3D: perspective 1200px, rotateX 28deg -> 4deg, rotateZ -10deg -> -3deg, translateY 70vh -> 0, тень под ней растёт и смягчается (настоящая box-shadow/filter drop-shadow 0 40px 60px rgba(0,0,0,.55)). Во время полёта карточка «проявляется»: filter invert(1) sepia(.6) -> invert(0) sepia(.15), contrast 1.4 -> 1. Фон темнеет на 35%. Подпись мелко под карточкой: «Пётр, лето 1941».
4. 48-68%. Карточка уходит в глубину влево (scale .7, blur 3px, opacity .5). Письмо-треугольник (letter.png) прилетает на передний план из правого верхнего угла с вращением, затем «раскрывается»: меняется на letter-open.jpg через 3D-разворот (rotateY 90 -> 0 у развёрнутого листа, сгиб по вертикали). На листе по прокрутке проступают строки письма курсивом Literata, цвет чернил #2b2a33, лёгкий наклон -1deg, каждая строка проявляется слева направо (clip-path): «Здравствуй, Маша.» / «У нас тихо третий день, даже птиц слышно.» / «Береги ребят, пусть Коля слушается.» / «Вернусь - достроим веранду, как хотели.» Справа от листа счётчик крупными цифрами 1 -> 37 и под ним мелко «писем сохранилось».
5. 68-86%. Лист уходит вниз и тускнеет. Сверху на ленте опускается медаль (medal.png, около 18vw по высоте): по прокрутке спускается на 60vh, качается как маятник (rotate -7 -> 5 -> -2 deg, затухание), по металлу проходит блик (наложенный градиент под маской медали, слева направо). Свет сцены холоднее (filter: saturate .7). Подпись: «12 июля 1943 года. Прохоровка.» / «Медаль «За отвагу» передали семье в 1946-м.»
6. 86-100%. Всё гаснет, кроме тумана. В центре крупной курсивной строкой по словам (каждое слово из прозрачности и размытия 6 px -> 0): «Маша, береги ребят. Вернусь - достроим веранду, как хотели.» и мелко «Из письма, май 1943». К 100% туман заливает экран светлым - конец пробы (ниже экран бумаги #f3ece0 с одной строкой «Дальше - глава о Николае» и кнопкой «Вернуться к древу»).
