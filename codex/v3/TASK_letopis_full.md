# «Летопись» v3 целиком
Цель: весь сайт «Летописи» в стиле одобренной пробы: экран закреплён, прокрутка ведёт раскадровку. У каждой главы СВОЯ режиссура (не шаблон «видео + рамка + 4 предмета»). Порядок страницы: герой (готов) -> древо -> глава Петра (готова) -> глава Николая -> глава Сергея -> глава Марии -> нижние разделы.

## Древо (закрепление 170vh, затем обычная прокрутка)
- Перенеси механику древа v2 (ленты-поколения с инерцией, связи-нити ко всем ближайшим копиям, клик выстраивает родню по вертикали, панель с кнопкой «Читать историю», только люди без предметов, колонка подписей поколений) в модуль tree.js.
- Вход по прокрутке: из чёрного после героя сверху вниз появляются поколения I -> V (каждое: маска снизу вверх + подъём 30 px), нити рисуются линией (stroke-dashoffset) от родителей к детям по мере прокрутки; к 60% древо целиком, ленты начинают ехать; заголовок «Из корней вырастаем мы.» буквами из маски.
- «Читать историю» и клик по людям с главами (petr, nikolay, sergey, maria) плавно ведут Lenis к главе (lenis.scrollTo, 1,6 с).

## Глава Николая - «мосты» (закрепление 600vh)
1. 0-15%. Экран становится синькой (#1f3a5f с бумажной фактурой). Белые технические линии сами чертятся (SVG stroke-dashoffset по прокрутке): ферма арочного моста, опоры, размерная линия с подписью «412 м». Сверху мелко «Глава вторая · Николай Петрович · 1931-2019». Подпись: «1954. Окончил строительный институт и попросился на мосты.»
2. 15-35%. Чертёж совмещается с видео bridge: линии арки остаются поверх и тают, видео проступает (маска от центра), камера медленно панорамирует вдоль моста (translateX -10vw, scale 1.15 -> 1.05). Искры сварки - мелкие частицы canvas, падающие с арки.
3. 35-52%. Огромное «1967» полупрозрачной заливкой позади, фотокарточка brigade приколота к кадру (влетает с поворотом, «втыкается» кнопкой - маленький круглый блик-канцелярская кнопка сверху). Подпись: «1967. Главный инженер участка на строительстве моста через Обь. 412 метров стали.» («412 метров стали» - акцент).
4. 52-72%. Кадр темнеет, через экран слева направо рисуется тонкая линия маршрута «Урал -> Енисей», по ней по прокрутке зажигаются 14 точек-мостов с годами (1958 ... 1987, равномерно), счётчик крупно 1 -> 14 «объектов». Подпись: «Тридцать лет на мостах: 14 объектов от Урала до Енисея.»
5. 72-88%. Штангенциркуль (caliper) влетает на передний план крупно (40vw), поворачивается из -20 в -4 градуса, рядом мелким техническим шрифтом-капителью выносная надпись «0,1 мм» с линией-выноской. Подпись: «Дома чинил всё сам. Штангенциркуль лежал у него в кармане даже на даче.»
6. 88-100%. Каска (helmet) на переднем плане слева в тени, крупная курсивная цитата по словам: «Мост должен стоять дольше, чем мы. Иначе зачем строить.» мелко «Николай Петрович, из интервью заводской газете, 1981». Переход: закат видео bridge выцветает в тёплый вечер следующей главы.

## Глава Сергея - «футбол» (закрепление 560vh), тон живее, рядом метка «Рассказывает сам»
1. 0-15%. Старое табло стадиона (CSS: чёрные ячейки, жёлтые сегментные цифры): «СТРОИТЕЛЬ 1 : 1 ГОСТИ», время по прокрутке 86:00 -> 87:59. Мелко «Глава третья · Сергей Николаевич · род. 1958».
2. 15-30%. На 88:00 цифра счёта переворачивается как перекидное табло -> «2 : 1», кадр вспыхивает (короткая засветка 0,3 по прокрутке). Видео football раскрывается за табло, табло уезжает вверх. Подпись: «1979. Кубок области. Победный гол на 88-й минуте.»
3. 30-48%. Мяч (ball) катится на переднем плане слева направо через весь экран (translateX -20vw -> 120vw с вращением 0 -> 720 deg, тень по земле), прожекторы пульсируют мягким свечением.
4. 48-66%. Командное фото teamphoto падает сверху как отпечаток (rotate 6 -> -2), затем на нём рисуется от руки кружок (SVG stroke, цвет акцента) вокруг одного игрока и подпись-выноска «Сергей, №7». Подпись: «1975. Пришёл в заводскую команду «Строитель» в 17 лет, правым полузащитником.»
5. 66-84%. Бутсы (boots) стоят внизу кадра, вымпел (pennant) качается на нитке сверху. Цвет кадра теплеет (вечер во дворе). Подпись: «После травмы колена двадцать лет тренировал мальчишек во дворе.»
6. 84-100%. Цитата крупно: «Играли в любую погоду. Главное - чтобы мяч был.» Переход к утру следующей главы светлой засветкой.

## Глава Марии - «школа» (закрепление 560vh)
1. 0-15%. Доска chalkboard на весь экран, по прокрутке мелом пишется (SVG-маска по штрихам или clip-path по буквам, мелкая меловая пыль частицами) «Мария Соколова» и ниже «1912-1998 · учительница». Мелко «Глава четвёртая».
2. 15-32%. Доска уходит, видео school: камера «въезжает» между партами (scale 1.3 -> 1.05, translateY 6vh -> 0), луч солнца ярче. Подпись: «41 год учила детей в сельской школе. Русский язык и литература.»
3. 32-55%. Раскрытая тетрадь notebook-open на переднем плане (с наклоном 3D rotateX 35 -> 12 deg), фиолетовыми чернилами по прокрутке пишется диктант по буквам курсивом: «Диктант. / Осень. Над рекой стоит туман. / Скоро зима.»; затем красной ручкой подчёркивается одно слово и на полях появляется оценка «5».
4. 55-72%. Глобус (globe) медленно поворачивается (небольшой rotate и смещение фона-блика), рядом счётчик лет 1 -> 41. Подпись: «В войну одна растила двух сыновей и вела уроки в две смены.»
5. 72-88%. Шесть конвертов (envelope) прилетают с разных краёв экрана и собираются в круг, у каждого мелко город: Тамбов, Москва, Казань, Самара, Пермь, Омск. Подпись: «На её 80-летие бывшие ученики приехали из шести городов.»
6. 88-100%. Цитата: «Пишите так, чтобы через сто лет было понятно, что вы хотели сказать.» Затем бумага #f3ece0 - вход в нижние разделы.

## Нижние разделы (обычная прокрутка с анимациями по прокрутке, на бумаге)

## Общее
- Lenis + ScrollTrigger как в пробе; все закрепления пересчитываются при resize; prefers-reduced-motion - статичная версия по порядку.
- 375x812: у каждой сцены свои мобильные позиции и размеры, ничего не обрезано и не перекрыто, древо со своими мобильными правилами из v2.
- Видео и тяжёлая графика работают только в зоне видимости.
