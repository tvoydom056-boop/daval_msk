# «Повод» v3
Цель: сайт-витрина подарков уровня студий 2026: тёплый, живой, кинематографичный. Пример: в v3/letopis/ (смотри src/main.js и style.css пробы как образец техники - Lenis, ScrollTrigger, подписи по строкам из маски), но тон другой: светлый, персиковый, с юмором.

## Сцена 0. Герой (как в v2, доведённый)
- 4 слайда-повода (видео slide-*), шторка справа налево с дымкой, колонка круглых миниатюр на кольцах, огромные градиентные заголовки, облака (clouds.mp4 screen) - перенеси механику v2 и улучши: заголовок каждого слайда собирается буквами из маски при смене, лёгкий параллакс фото за курсором (±0,6%).
- Прокрутка (закрепление 120vh): облака поднимаются и растут, фото уходит вглубь (scale 1 -> 1.12, blur 0 -> 6 px), в облаках проступают карточки поводов (сцена 1).

## Сцена 1. Поводы (закрепление 140vh)
- 5 карточек (4 повода + «Свой повод») выезжают веером из облаков: по прокрутке раскладываются из стопки в ряд (каждая со своим поворотом -8..8 deg -> 0), над ними крупно «Выберите повод». Наведение: подъём и проигрывание видео повода внутри карточки. Клик: перелёт фото карточки в полноэкранный кадр лендинга повода (900 мс), маршрут #wedding и т.д., кнопка «назад» браузера работает.

## Сцена 2. История повода как фильм (лендинг #wedding; закрепление 600vh)
1. 0-14%. Белый экран, рукописно (Caveat) пишется по прокрутке «Как всё началось», затем фото story-meet проявляется как полароид (белая рамка, проявка из серого 0 -> 100% за прокрутку).
2. 14-30%. Полароид растягивается в полный экран и становится видео story-meet. Подпись-плашка комикса: «2019. Кофейня на Покровке, он опоздал на 20 минут». Рядом маленький «стикер» - часы со стрелкой, которая по прокрутке отматывает 20 минут.
3. 30-48%. Переход «билет»: на экран влетает билет на поезд/самолёт (CSS: бумажный билет с перфорацией, «Москва -> Море»), отрывается контроль по линии перфорации, за ним открывается видео story-trip. Подпись: «Первое море вдвоём. Она боялась высоты, он держал за руку».
4. 48-68%. Ночь: экран темнеет, видео story-proposal, по прокрутке зажигаются огни города (мерцающие точки canvas), кольцо (простая SVG-иконка кольца с бликом) поднимается к центру. Подпись: «Крыша, ноябрь, плюс два. Она сказала «да» раньше, чем он договорил».
5. 68-86%. Утро: светлеет, видео story-today, по экрану проходит отпечаток лапы (несколько SVG-следов по диагонали по прокрутке). Подпись: «Сегодня у них есть собака Булка и сайт, который откроют на свадьбе».
6. 86-100%. Письмо Caveat на бумаге, строки проступают по прокрутке (текст письма из data.js для свадьбы), подпись «А это - ваш подарок» и переход к примеру в телефоне.
- Для birthday, anniversary, jubilee - та же структура из 4 сцен на их фото (povod/assets/img bday-uni, bday-hike, birthday; anni-first, anni-home, anniversary; jub-young, jub-family, jubilee) и подписях из data.js, переходы между сценами - разные (засветка, шторка, полароид).

## Сцена 3. Подарок в телефоне (закрепление 200vh)
- Телефон в центре, его содержимое прокручивается вместе с прокруткой страницы (scrub): все блоки примера из data.js (главы, голосовые с волной, письмо, галерея, счётчик, причины, квиз, рецепт, финал). Вокруг телефона по сторонам всплывают подписи «Голосовые от друзей», «Рукописное письмо», «Квиз про героя» в момент, когда этот блок в телефоне.
