# Этап 8. Эффекты между страницами и полировка

Правило: эффект служит переходу или смыслу, а не украшению. Не больше 1-2 новых эффектов на страницу, всё отключается при prefers-reduced-motion.

## 1. Переходы между страницами (главное)
- Кросс-документные View Transitions (`@view-transition { navigation: auto; }`) для всех страниц сайта: мягкое растворение 0,5 с вместо белой вспышки при переходе.
- «Полёт карточки»: фото карточки примера на главной (и на families.html) имеет view-transition-name, такое же имя у главного фото/фона первого экрана страницы примера (Галина - обложка, Пётр - поле титра, Семейное древо - фон древа, Мария, Сергей - их первые кадры). При переходе карточка плавно вырастает в первый экран. Если браузер не поддерживает - обычный переход, без ошибок.

## 2. «Наши семьи»: лента, которую можно тянуть
Над сеткой карточек на families.html - горизонтальная лента крупных фото всех пяти страниц (по 2-3 кадра на страницу из уже имеющихся медиа). Медленно едет сама, её можно тянуть мышью и пальцем с инерцией, при отпускании продолжает ехать. Клик по кадру - на страницу примера. Тянуть - не значит кликнуть (порог 6 px).

## 3. Главная, «Как это работает»
Между четырьмя шагами по прокрутке прорисовывается тонкая линия (stroke-dashoffset), каждый шаг «зажигается» акцентом, когда линия до него доходит.

## 4. Скорость и вес
- Видео на страницах примеров грузятся только когда до них остаётся меньше экрана (preload none + IntersectionObserver), на телефоне - версии меньшего размера, если есть, иначе постер до касания экрана.
- Картинки ниже первого экрана - loading="lazy", decoding="async"; у всех задан width/height (без прыжков вёрстки).
- Отчёт: вес первой загрузки главной (HTML+CSS+JS+медиа первого экрана) до и после.
