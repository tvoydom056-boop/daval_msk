# Повод: пять спокойных лендингов

Пять автономных HTML/CSS/JS концепций для сравнения дизайна. Главная index.html - навигатор. Полная вёрстка и живой текст, без картинок вместо сайта. Никаких зависимостей и сборки.

## Запуск

Из этой папки:

```powershell
python -m http.server 8865 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8865/ . Для ES modules нужен HTTP-сервер, а не двойной щелчок по файлу.

## Варианты

- 01-editorial/ : Тихая редакция, широкое фото и литературная типографика
- 02-garden/ : В саду, панорамный вход и шалфейная палитра
- 03-archive/ : Личный архив, боковая колонка и асимметричная картотека
- 04-letter/ : От руки, личное письмо и пыльно-розовая палитра
- 05-voice/ : Близкий голос, голосовой первый экран и дымчатый синий

В каждой папке index.html и styles.css. shared/base.css и shared/app.js общие: шрифты, доступность, меню, переключение поводов и проверка демо-формы. media/ - оптимизированные WebP. fonts/ - локальные Onest и Caveat с лицензиями. kit/ - слой входной анимации, hover и одного текстового момента. Референсы и права на материалы в SOURCES.md.

## Демонстрационные ограничения

Формы не отправляют запросы и не сохраняют введённые данные. При выключенном JS поля остаются отключёнными. Без исходного аудиофайла кнопки прослушивания отключены с пояснением. Люди и истории вымышлены. Сроки, цены, отзывы и действующие контакты не добавлены.

## Проверка

Результаты browser QA и скриншоты находятся в qa/ и previews/ после проверки. Для повторного браузерного прогона нужен установленный Playwright; передайте путь к нему параметром --playwright-module, а адрес запущенного сервера параметром --url. Основная вёрстка не требует Playwright.
