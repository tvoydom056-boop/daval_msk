# Проверка пяти лендингов

## Основной браузерный прогон

qa/check.mjs проверяет пять страниц на 1440x900, 1024x768, 768x1024, 390x844, 375x812. Проверяются размеры контента, первая кнопка, фотографии, H1, alt, ошибки консоли и ресурсов. Сценарии: мобильное меню, Escape, якорь из меню, переключение поводов, FAQ, ошибки формы и фокус первого поля, локальная валидация без сетевой записи, disabled-аудио, skip-link и reduced motion. Результат каждого запуска в results.json. Скриншоты в previews/.

Визуально просмотрены первые экраны всех пяти и полные мобильные страницы. Исправлены конфликт шаблонного layout-слоя с кастомными сетками, блокировка FAQ и кадрирование hero-фото.

## Дополнительные проверки

- Copy lint: 0 FAIL для всех пяти, у первой страницы предупреждение о количестве коротких eyebrow-подписей
- Moments: один word-highlight на страницу, WebGL не используется
- Perf первой страницы: 0 FAIL, 4 WARN о числе файлов шрифтов и разрешении фото. CLS 0, broken requests 0
- Штатные consistency и finish gate не завершились за ограниченное время. Их статус ERROR/timeout, не PASS. Повтор одинаково зависающих прогонов прекращён
- Jev judge недоступен. Формального одобрения плана нет; самопроверка плана и реальный браузерный прогон зафиксированы отдельно

Ни backend, ни отправка заявок, ни воспроизведение настоящего аудио не реализованы. Это явно обозначено в интерфейсе.
