# Летопись v4 - план доводки

Статус каждого этапа: ждёт / принят / отклонён (с правками). Следующий этап начинается после «принято» по предыдущему.
Цены - из PLAN.md, раздел тарифов. Claude только предлагает, решаем вдвоём.

## Что не так сейчас (из разбора 26.11.2026)
- Всё на одной длинной странице: представление, древо, четыре фильма, цены. До цен доходят немногие.
- Меню (Древо, Истории, Цены) теряется на видео.
- После тумана в начале чёрная полоса, потом жёсткий шов перед следующим блоком.
- Нет главной страницы с выбором «что посмотреть», ценами и условиями.
- Примеры не привязаны к тарифам. Древо на 21 человека: биографии есть только у четырёх.
- Нет юридической части (персональные данные, согласие на публикацию, оферта).
- Все главы в одном стиле, хотя разные люди должны выглядеть по-разному.

## Новая структура сайта
| Страница | Что там | Тариф |
|---|---|---|
| Главная | Представление (туман остаётся, сразу перетекает в содержимое), три входа в примеры, как это работает, цены и условия, «Наши семьи», свеча, вопросы, заявка | - |
| Пример 1. «Страница памяти» | Один человек, короткая история (до 3 000 знаков), 10-15 фото, свеча. Свой стиль | 3 990 ₽ |
| Пример 2. «История жизни» | Один человек, полная история-фильм (Пётр, нынешний стиль с письмами и медалью, доведённый) | 7 900 ₽ |
| Пример 3. «Семейное древо» | Древо на 12 человек (4 поколения). Клик по человеку - выпадает его биография с фото и предметами. Одна подробная история | от 14 900 ₽ |
| Наши семьи | Галерея страниц, которые семьи разрешили показывать (в макете вымышленные, с пометкой «пример») | - |
| Документы | Политика персональных данных, согласие на обработку, согласие на публикацию сведений об умершем, оферта, условия хранения | - |

У каждого примера внизу плашка тарифа: что входит, цена, «Хочу так же».

## Этапы

### Этап 0. Наладить работу с Codex (до любой вёрстки)
- Единый файл правил для Codex `codex/v4/RULES.md`: стиль, шрифты, явные цвета, защита от стилей хоста, запрет чёрных пустых экранов, как сдавать.
- Скрипт автопроверки `codex/v4/qa.py`: кадры 1440/375 по ключевым точкам прокрутки, проверка цвета текста, горизонтальная прокрутка, детектор пустых тёмных экранов (кадр почти целиком одного тёмного цвета), ошибки консоли. Выдаёт лист кадров и отчёт.
- Пробую дать Codex запуск браузера, чтобы он сам смотрел свои кадры. Если не выйдет, проверку запускаю я после каждой порции.
- Работаем маленькими порциями: одна страница или один блок, я смотрю кадры, правлю мелочи сам, крупное возвращаю Codex с конкретными пунктами.
- Проба: Codex делает одну небольшую вещь (плашки меню и шов после тумана), я оцениваю, как он понял правила.

### Этап 1. Карта сайта и каркас главной
- Разделить проект на страницы (Vite multi-page): главная, три примера, наши семьи, документы.
- Меню на плашках, видно на любом фоне. На телефоне - кнопка меню.
- Главная: представление с туманом без чёрной полосы, три карточки входа в примеры, цены и условия. Остальные блоки пока заглушками-структурой.
- Сдаю: ссылку на опубликованную главную.

### Этап 2. Тексты
- Пишу сам: короткая история для «Страницы памяти» (новый человек), доводка истории Петра, биографии 12 человек древа (по 0,5-1 страницы, подробная - одна), тексты главной: как это работает, что входит, сроки, вопросы.
- Сдаю: документ с текстами на согласование до вёрстки.

### Этап 3. Изображения
- Через ChatGPT (Codex): портреты 12 человек древа в разные эпохи, фото для новой «Страницы памяти», предметы для биографий (вырезанные PNG), обложки карточек «Наших семей».
- Syntx (до 500 токенов): свеча, которая зажигается (луп), плюс 1-3 коротких атмосферных ролика для новых стилей.
- Я отбираю и бракую кадры до вёрстки.

### Этап 4. Пример «Семейное древо»
- Древо 12 человек, понятное с первого взгляда. Клик - панель биографии (фото, годы, текст, предметы, «читать подробно» у главного героя). Переходы между родными прямо из панели.
- Сдаю: ссылку.

### Этап 5. Пример «История жизни» (Пётр)
- Доводим нынешний фильм: без пустых экранов, связные переходы, полный текст книжной страницей.

### Этап 6. Пример «Страница памяти»
- Новый человек, другой стиль (светлый, спокойный). Короткая страница, которая хорошо выглядит и за 3 990 ₽.

### Этап 7. Свеча, «Наши семьи», документы
- Свеча: видео-луп, нажал - зажглась, счётчик. В макете счётчик хранится в браузере; настоящий общий счётчик - на сервере в рабочей версии (API из ARCHITECTURE.md).
- Галерея «Наши семьи».
- Юридические тексты по 152-ФЗ, реквизиты - заглушкой до решения, на каком лице работаем.

### Этап 8. Эффекты и полировка
- Эффекты по референсам с сайта, который пришлёт Виталий. Подбор по одному-два на страницу, без перегруза.
- Скорость загрузки, телефон, reduced motion.

### Этап 9. Приёмка
- Отдельный агент-проверяющий проходит весь сайт как клиент. Исправления. Публикация, GitHub (ветка + PR).
