# Летопись: бумажный семейный альбом

Отдельная визуальная концепция по скрапбук-референсу пользователя: кремовая бумага, бордовый картон, семейные фотографии в рамках, скотч, письма и крупная типографика Literata. Caveat используется только в письме.

Ветка: `site/letopis-scrapbook`. Исходные макеты `letopis/`, `povod/` и v3 не изменялись. Вымышленная семья и фотографии переиспользованы из существующих макетов.

Запуск из корня этого репозитория:

```powershell
python -m http.server 8767 --bind 127.0.0.1
```

Открыть [семейный альбом](http://127.0.0.1:8767/letopis-scrapbook/).

Главные файлы: `index.html`, `styles.css`, `app.js`. Ресурсы находятся в `assets/`; внешние CDN при просмотре не требуются. Зависимостей для запуска нет.

Работают открытие фотографий, фильтры, чтение глав при прокрутке, биографии родных, мобильное меню, подсветка медиа-слотов и демонстрационное воспоминание. Текст демо хранится только в памяти вкладки до перезагрузки; форма предупреждает об этом.

Проверка в Edge headless: 1440x900, 768x1024, 375x812 и 320x812. Пройдены пользовательские действия; горизонтальной прокрутки, сломанных изображений и ошибок консоли нет. При reduced motion главы показаны статично. Подробности и ограничения дизайн-чекера - в `CHECKS.md`.

`python build_artifacts.py` выполнен для существующих макетов. Отдельная концепция этим скриптом пока не упаковывается. PDF-отчёт не пересобирался, скриншоты новой концепции в него не включены. Публикации и отправки изменений в GitHub не было.
