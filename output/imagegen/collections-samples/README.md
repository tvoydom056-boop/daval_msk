# Тематические PNG: пробники для утверждения

36 тестовых PNG, по 3 на каждую из 12 тем. Полный план содержит 150 новых позиций. Все образцы созданы встроенным imagegen с прозрачным фоном.

Статус: ожидается утверждение тем, стиля и формата одежды. Полная серия ещё не сгенерирована. После утверждения всех 36 образцов останется 114 новых PNG.

## Файлы

- `PLAN.md` - план и полный список 150 позиций.
- `planned-catalog.json` - машинный список всех 150 запланированных позиций.
- `catalog.json` - только 36 реально сгенерированных образцов, их ID, пути, размеры, SHA-256 и промпты.
- `prompts.txt` - полный набор промптов для образцов.
- `<theme>/png/` - по 3 отдельных PNG каждой темы.

Все пути `file` считаются относительно этой папки. ID образцов совпадают с ID полного плана, чтобы после утверждения использовать эти же изображения в библиотеке.

## Одежда

Три образца: мужской пиджак с рубашкой и галстуком, женская блузка, женское бордовое платье. Показаны плечи и грудь, головы и шеи нет. Для монтажа положите вырезанный портрет с шеей под слой одежды и совместите его с горловиной. Формат одежды пока предложен для просмотра; в полном плане предусмотрены 8 мужских и 8 женских вариантов.

## Переиспользование

Выбирайте PNG по ID или теме. Для новой генерации прикрепляйте выбранное изображение и описывайте композицию. Прозрачность и пропорции исходника сохраняйте; размеры указаны в каталоге. Для теннисной ракетки сохранена дополнительная инструкция очистки фона в `edit_prompt`.

Пробники пока хранятся локально для утверждения. После выбора стиля библиотека будет собрана в `assets/collections/<theme>/png/` с общим каталогом и промптами.
