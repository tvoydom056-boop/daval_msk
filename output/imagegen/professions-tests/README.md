# Профессии: тестовые PNG

Первые 5 образцов перед серией из 50 предметов для «Летописи».

- Отдельный реалистичный предмет в каждом PNG, фон прозрачный.
- Все изображения созданы встроенным imagegen.
- В catalog.json сохранены ID, профессии, пути, размеры, SHA-256 и промпты.
- В prompts.txt сохранены инструкции для повторной генерации.
- Для переиспользования прикрепляйте нужный PNG и описывайте новую композицию.

Это тестовый набор для просмотра стиля. Полная библиотека и публикация в GitHub относятся к следующему этапу.
