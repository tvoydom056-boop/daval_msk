## Воспроизводимая проверка

Из корня проекта:

```powershell
python research/letopis-life-details-2026-11-28/build_gallery.py
node research/letopis-life-details-2026-11-28/check_gallery.mjs --playwright-module "<путь-к-playwright>"
```

Вместо аргумента допускается `PLAYWRIGHT_MODULE_PATH`; нужен установленный Edge. Генераторы второй и третьей галерей вызывают общий `research/build_letopis_catalog.py`. Он обнаруживает манифесты серий, вычисляет суммарное количество заданий и отдельно считает фактически существующие изображения. Порядок пересборки этих галерей не должен уменьшать общий каталог до 100.

Браузерный QA проверяет ID 101-120, четыре фильтра по пять карточек, загрузку 20 оригиналов, пять CSS-подложек прозрачных деталей, полные промпты и общий каталог на 1440 и 375 px. Финальный результат 35/35 PASS и восемь снимков сохранены в `qa/`. У второй серии актуальный результат 37/37 PASS хранится в её `qa/results.json`.
