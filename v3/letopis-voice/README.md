# Одна история - технический пилот «Летописи»

Локальная страница «Ключ от первого дома»: один вымышленный эпизод, короткий текст, три AI-иллюстрации и синтетическая озвучка длительностью 4:14. Основа - [бриф внутреннего пилота](../../research/family-stories-night-2026-11-28/PILOT_BRIEF.md). Это проверка читательского интерфейса, не новый клиентский пакет.

## Посмотреть

Открыть `index.html` в Edge или Chrome. Все материалы и шрифт находятся рядом, подключения к интернету для страницы не нужны.

Для HTTP-просмотра из этой папки:

```powershell
npm exec --yes --package=serve@14.2.5 -- serve . --listen tcp://127.0.0.1:8773 --no-clipboard --no-request-logging --no-port-switching
```

Нужны Node.js и npm; первый запуск скачивает инструмент статического просмотра. Сборки приложения и backend нет. Для перемотки аудио сервер должен поддерживать HTTP byte ranges. В проверенном Edge обычный `python -m http.server` отдавал файл без этой поддержки: звук играл, но позиция при перемотке сбрасывалась. Проверенный сервер `serve` возвращает `206` на Range-запрос.

- [С фотографиями](http://127.0.0.1:8773/)
- [Только рассказ и голос](http://127.0.0.1:8773/?case=audio-only)
- [Неподтверждённая дата](http://127.0.0.1:8773/?case=uncertain-date)

Без JavaScript доступны основной текст и нативный аудиоплеер. Параметры сценариев применяет JavaScript. Технические переключатели не показаны читателю.

## Что реализовано

Шесть смысловых блоков брифа: эпизод и примерная дата, вымышленная рассказчица, аудио, редакция рассказа, иллюстрации и предмет, происхождение материалов. Сохранены Literata и тёплая палитра исходной «Летописи»; вторичный текст затемнён для чтения.

Кнопка «Слушать историю» переводит к плееру и включает запись. Плеер воспроизводит настоящий MP3, поддерживает паузу и перемотку, управляется клавишами Space и стрелками. Автозапуска при открытии нет. При ошибке загрузки остаются текст и сообщение. Учтены видимый фокус и reduced-motion. В варианте без фотографий скрыты все иллюстрации, пустая галерея не остаётся. Вариант с разными датами сохраняет приблизительный период.

## Материалы и воспроизведение подготовки

- [Исходный вымышленный текст](source/story.txt) написан специально для этого примера. Короткая редакция находится в `index.html`; это редакция того же эпизода, а не расшифровка настоящего интервью.
- `assets/story.mp3`: Microsoft Irina Desktop, локальный System.Speech, rate -1; затем моно MP3 64 kbit/s через ffmpeg. Продолжительность 253.626848 с, размер 2 029 861 байт. Начало и конец записи прямо сообщают о вымысле и синтезе.
- [Происхождение изображений](assets/images.json): ID 12, 31 и 117 из ветки `content/letopis-visual-bank-100`, снимок банка `5317b007395f36d25393cf217f45834694b5d305`. В манифесте исходные относительные пути, размеры и SHA-256. WebP подготовлены уменьшением и кодированием, содержание изображений не редактировалось.
- `assets/literata.ttf`: [официальный Google Fonts](https://github.com/google/fonts/tree/main/ofl/literata), обычное вариативное начертание. [Лицензия SIL OFL](assets/OFL.txt) сохранена рядом.

Пересоздать запись в Windows с установленным русским голосом и ffmpeg:

```powershell
powershell -NoProfile -File source/make_audio.ps1
```

Подготовить изображения заново при наличии checkout банка и Pillow:

```powershell
python source/prepare_images.py "PATH_TO_BANK"
```

## Проверка

Из корня репозитория при запущенном сервере:

```powershell
node v3/letopis-voice/qa/check.mjs --url http://127.0.0.1:8773/ --playwright-module "PATH_TO_PLAYWRIGHT"
```

Вместо последнего параметра можно использовать `PLAYWRIGHT_MODULE_PATH`. Нужны установленный Playwright и Edge. Скрипт проверяет основной и два ограниченных сценария на 1440x900 и 375x812, реальное воспроизведение до и после перемотки, клавиатуру, шрифт, ресурсы, консоль, переполнение, no-JS, ошибку аудио и прямое открытие файла. Снимки и JSON пишутся в `qa/` и исключены из git. Итог и визуальный просмотр записаны в [QA.md](qa/QA.md).

## Границы прогона

Человеческая запись не предоставлялась. Синтезатор читает вымышленный текст и не изображает голос женщины на портрете; клонирования нет. Так проверен интерфейс, но не производство настоящей семейной истории. Реальные интервью, разбор присланных материалов, согласие, редакторское согласование и обратная связь семьи не проводились. Их нельзя считать пройденными или использовать этот пример как доказательство спроса, цены и срока заказа.

Загрузки, оплаты, аккаунтов и защищённого клиентского доступа нет. Сайт не публиковался. Цены и пакеты не менялись. Исходная статика и её `artifact.html` не затронуты; прежний PDF этот прототип не покрывает.
