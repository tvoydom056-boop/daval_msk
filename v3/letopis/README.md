# Летопись v3

Локальный сайт на Vite, vanilla JavaScript, GSAP ScrollTrigger, Lenis и Literata. Данные вымышленной семьи и тексты нижних разделов перенесены из названных источников v2, их вёрстка не используется.

## Команды

```text
npm run dev
npm run build
npm run preview
```

Сборка использует base './'. node_modules находится в папке проекта. Кэш установки: npm_config_cache=D:/CLAUDE_Apps/npm-cache.

## Сцены

Порядок: hero, tree, petr, nikolay, sergey, maria, нижние разделы.
Закрепления в vh: герой 115, древо 220, Пётр 620, Николай 600, Сергей 560, Мария 560, реставрация 120, горизонтальная галерея 360.
Сумма 3155vh + 800vh естественной высоты сцен + обычные нижние разделы, примечания реставрации и футер.
Древо сохраняет инерционные ленты, связи между ближайшими копиями, выравнивание родни и навигацию Lenis.
Переходы между четырьмя главами ведут прямо в синьку, табло и доску. Бумага появляется после Марии.
Туман процедурный; fog.mp4 не используется. Тяжёлая графика и видео работают в зоне видимости. Reduced-motion даёт статичную последовательность.

## Модули

src/scenes/ - отдельные главы, древо и нижние разделы.
src/lib/ - туман, зерно, частицы, подписи, счётчики, превью галереи и переходы.
src/data.js - исходные данные и тексты.
src/style.css и src/scenes.css - базовая вёрстка, src/presentation.css - последняя режиссёрская правка древа, подписей и нижних разделов.
public/media/ - копии названных медиа, включая локальные сгенерированные доску, тетрадь, конверт и письмо.
Форма заявки остаётся макетом и явно сообщает, что ничего не отправляет.

## Проверка и кадры

Проверка сборки: npm run build.
Проверки логики, исходных данных и расчётов лежат в codex/v3/qa. Happy DOM не проверяет браузерную вёрстку.
Съёмка при работающем preview:

```text
python capture_all.py --url http://127.0.0.1:4173/
```

Запуск из codex/v3. Требуются Python, playwright, pillow, fonttools, brotli и Chromium (или --browser msedge).
Скрипт ждёт сеть, использует window.__lenis.scrollTo с immediate:true и паузу 700 мс, проверяет метрики закреплений, переполнение и интерактив.
Снимает hero/tree/petr/nikolay/sergey/maria/benefits каждые 4% и шесть кадров нижних разделов на 1440x900 и 375x812: 376 кадров, 16 листов sheet_<сцена>_<ширина>.jpg.
Старые скрипты и снимки сохранены. После последней правки новые кадры ещё не сняты: Chromium в окружении исполнителя недоступен, визуальную приёмку выполняет режиссёр.
