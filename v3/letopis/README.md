# Летопись v3 - фильм с прокруткой

Отдельная проба: герой и глава Петра. Vite 8, vanilla JS, GSAP ScrollTrigger, Lenis. Предыдущая вёрстка не использовалась. Шрифт Literata Variable хранится локально и содержит обычные и курсивные начертания.

## Запуск

Из этой папки:

```powershell
$env:npm_config_cache='D:/CLAUDE_Apps/npm-cache'
npm install
npm run dev
```

Разработка: http://127.0.0.1:5173/

```powershell
npm run build
npm run preview
```

Собранная версия: http://127.0.0.1:4173/. `base: './'` позволяет разместить содержимое `dist/` в произвольном подкаталоге HTTP-сервера. Открытие ES-модулей через `file://` браузеры ограничивают, для просмотра нужен preview или другой HTTP-сервер.

## Сцены

- Герой: вступление при загрузке, затем закрепление 115vh, камера, уход типографики, два слоя тумана с 35%, покрытие к 72%, чёрный к 88%. Подзаголовок и приглашение листать видны с первого кадра.
- Глава: одна timeline длиной 620vh с метками 0, 12, 30, 48, 68, 86, 96, 100. Год, поле, проявление фотографии, раскрытие письма и строки, счётчик, медаль с маятником и бликом, последняя цитата и светлая бумага.
- В финальном кадре главы на 100% показан тизер «Глава вторая / Николай Петрович / Мосты, которые стоят до сих пор» и кнопка возврата к древу. Он находится внутри закреплённой сцены, отдельного пустого экрана после неё нет. Сумма закреплений 735vh, естественная высота двух сцен 200vh, длина страницы 935vh.
- Для ширины до 767 px заданы отдельные размеры и координаты. При reduced motion нет Lenis, закреплений и scrub; шесть эпизодов идут статично друг за другом, видео остановлены.
- «Древо» и нижняя кнопка открывают небольшой просмотр Петра и Николая; «Истории» возвращает к главе. «Цены» честно сообщает о границах пробы.

## Медиа

Указанные в задании файлы скопированы в `public/media/` без изменений. Новый `letter-open.jpg` создан встроенной генерацией, без текста. Итоговый промпт: `letter-open.prompt.txt`.

## Кадры и проверки

Скрипт: `../../codex/v3/capture_film.py`. Зависимости: `pip install playwright pillow fonttools brotli`, браузер: `python -m playwright install chromium`.

При работающем preview:

```powershell
python ../../codex/v3/capture_film.py
```

Снимет 104 кадра: 26 кадров героя и 26 главы для каждой ширины 1440x900 и 375x812. Сохранит `sheet_film_1440.jpg`, `sheet_film_375.jpg`, папку `frames_film/`, снимки reduced motion и `film_audit.json` рядом со скриптом. Каждый шаг вызывает `window.scrollTo` и `window.__lenis.scrollTo` с `immediate:true`, ждёт 700 мс, затем завершает интерполяцию scrub для точного кадра. Проверяет переполнение, размеры заголовка и года, сумму закреплений, обратную прокрутку, кнопки, диалоги и reduced motion.

Альтернативный браузер: `python ../../codex/v3/capture_film.py --browser msedge`.
Только расчёты: `python ../../codex/v3/capture_film.py --math-only`.

Проверено здесь: production build, preview HTTP 200, доступность подключённых медиа и локальных шрифтов, синтаксис JS/Python, геометрия шрифта и формула длины страницы. Полная браузерная проверка и измерение 60 fps не подтверждены: Playwright блокируется песочницей с WinError 5, встроенный браузер сообщает, что его host недоступен. Контактные листы появятся после запуска скрипта в среде с доступным браузером.
