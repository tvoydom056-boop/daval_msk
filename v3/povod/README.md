# Повод v3

Кинематографическая витрина сайтов-подарков. Vite, vanilla JavaScript, GSAP ScrollTrigger, Lenis. Локальные Onest и Caveat. Данные v2 сохранены в `src/data.js`, медиа скопированы в `public/media`.

```powershell
$env:npm_config_cache='D:/CLAUDE_Apps/npm-cache'
npm install
npm run dev
```

Разработка: http://127.0.0.1:5174/. Сборка: `npm run build`. Просмотр сборки: `npm run preview`, http://127.0.0.1:4174/. `base: './'` позволяет разместить сборку в подпапке.

- Главная: герой с 4 слайдами, облака и веер из 5 карточек.
- Главный выбор: карточки 17vw на компьютере и 64vw на телефоне, названия 22px и цены 16px. На телефоне нативная горизонтальная лента со snap и инерцией.
- Маршруты: `#wedding`, `#birthday`, `#anniversary`, `#jubilee`; возврат к главной `#home`, поддерживается история браузера.
- Закрепления: герой 120vh, поводы 140vh, свадебная история 1100vh, остальные истории 600vh, телефон 200vh.
- Свадьба: 10 сцен, 10 переходов и палитр, слои bg/fg, параллакс, дождь, ночные огни и 72 лепестка на canvas. Интерфейс и фон меняют цвет вместе со сценами. В остальных поводах по 5 сцен.
- Подписи истории: 26px на компьютере и 20px на телефоне, год/событие 15px, плашка до 520px с отступами 22px/28px. Финальное письмо 44vw/88vw, Caveat 30px/22px, финальный заголовок 40px. При 0% сразу виден диагональный кадр; замочная скважина открывает фотографию home поверх предыдущей сцены и полностью снимает маску после раскрытия.
- Композиции из новых слоёв находятся в `public/media/story`. При запуске видео оно заменяет фон и вырезанных людей одним кадром; передний план со светом, эффектами и предметами сохраняет объём без двоения.
- В телефоне отображаются все блоки соответствующего подарка из data.js. Прокрутка страницы листает содержимое. Стрелки и Page Up/Down работают при фокусе на экране телефона.
- При `prefers-reduced-motion: reduce` страницы становятся последовательным документом, видео не играют, пример в телефоне можно листать внутри экрана.
- Записей голоса в исходных материалах нет. Плеер сообщает об этом. Форма заявки демонстрационная, ничего не отправляет.

## Проверка и кадры

Из `codex/v3`:

```powershell
python capture_povod.py --math-only
python capture_povod.py --url http://127.0.0.1:4174/
```

Нужны `playwright`, `pillow`, `fonttools`, `brotli` и браузер Playwright. Можно передать `--browser msedge`, `--project`, `--output`. Свадебная история снимается каждые 2% (51 кадр на ширину), остальные закрепления каждые 4%. Скрипт сохраняет 270 кадров, 10 листов `sheet_povod_<сцена>_<ширина>.jpg` и JSON-аудит. Проверяет геометрию, палитры, подписи, 10 точек прогресса, отсутствие двойных людей при видео, маршруты, историю браузера, FAQ, форму, квиз, причины, обратную прокрутку и статичный режим. `--math-only` не запускает браузер и не создаёт скриншоты.

Браузерная визуальная приёмка выполняется режиссёром. Расчёт метрик шрифтов и DOM-проверка не заменяют её.
