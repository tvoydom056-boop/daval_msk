# Повод v3

Актуальный прототип витрины сайтов-подарков в ветке `site/povod-clear-redesign`. Vite и обычный JavaScript, локальные шрифты Onest и Caveat. Это демонстрационный интерфейс: люди и истории вымышлены, цены тестовые, форма ничего не отправляет.

## Запуск

Нужны Node.js и npm. Из корня репозитория:

```powershell
cd v3/povod
npm ci
npm run dev
```

Разработка: http://127.0.0.1:5174/. Команды сборки и просмотра выполняются из той же папки:

```powershell
npm run build
npm run preview
```

Просмотр сборки: http://127.0.0.1:4174/. Сборка находится в `dist/`, относительный `base: './'` позволяет размещать её в подпапке. Открытие исходного `index.html` двойным кликом не заменяет Vite.

## Интерфейс

- Пять маршрутов: `#home`, `#wedding`, `#birthday`, `#anniversary`, `#jubilee`, с историей браузера.
- На главной статичное превью юбилейного подарка и открытая сетка поводов. Прокрутка обычная, без закреплённых сцен и управления прокруткой через Lenis.
- На странице видны пример подарка, его состав, три шага заказа, пакеты, FAQ и заявка. Полный подарок открывается нативным `details` и читается в потоке страницы.
- На свадьбе доступны только «История» и «Премиум». Выбор пакета переносится в форму; смена повода обновляет доступные форматы.
- В hero и рядом с примером указаны его формат и цена. Соответствующая карточка цены помечена «Как в примере выше», чтобы было понятно, какой пакет показан.
- У формы видимые подписи, обязательные имя и контакт, необязательная дата. Перед отправкой написано, что это демо. Материалы и оплата не принимаются.
- Onest используется в интерфейсе, Caveat только в письмах. Вымышленные истории и сгенерированные фотографии помечены. Голосовые без исходных записей не изображают работающий плеер.

Содержимое и цены находятся в `src/data.js`, сборка маршрутов и форма в `src/main.js`, секции в `src/scenes/`, оформление в `src/style.css`, медиа в `public/media/`. Активные DOM- и медиапомощники вынесены в `src/dom.js`; `src/shared.js` сохраняет прежний API для старых сцен. Активный JS больше не включает GSAP. Сохранившиеся файлы старых фильмов и захватов не описывают текущий интерфейс.

## Адаптивные изображения

Исходные JPEG сохранены. Для 16 изображений подготовлены 48 WebP-вариантов шириной 480, 960 и 1440 px в `public/media/responsive/`. Размеры и пути находятся в `src/image-sizes.json`; помощник `image()` использует их для `srcset`, `sizes`, `width` и `height`.

После изменения исходных фотографий выполните из корня репозитория:

```powershell
python codex/v3/prepare_povod_images.py
```

Нужны Python и Pillow (`python -m pip install pillow`). Скрипт обновляет WebP и метаданные, исходные JPEG не меняет. Затем заново соберите проект.

## Проверка

Текущая версия прошла выпускную проверку: 293/293 PASS, 22 варианта страницы, 56 снимков в Edge 158. Ошибок консоли, страницы, ресурсов и прерванных запросов нет. История браузера сохраняет раскрытый пример и позицию прокрутки. Copy-lint: 0 FAIL/0 WARN.

После оптимизации объём передачи составил 355,1 КиБ вместо 2 108,6 КиБ; изображения 146,2 КиБ вместо 1 857,7 КиБ. Отсутствующих размеров изображений, слишком крупных файлов, битых ресурсов и CLS не обнаружено. Осталось замечание линтера к 10 файлам шрифтов объёмом 183,8 КиБ.

Taste Skill 2.5.1 уже был установлен и использован без переустановки. Полный consistency-прогон завершён с 213 FAIL/59 WARN: реальные замечания к тексту, фокусу, заголовкам, контрасту и скролл-эффектам устранены; формальный PASS Taste не заявляется. План Claude, доказательства выпускной проверки и объяснение оставшихся формальных исключений находятся в [POVOD_CLEAR_STATE.md](../../codex/v3/POVOD_CLEAR_STATE.md).

Для браузерной проверки нужен уже установленный JavaScript-пакет Playwright и Edge. При запущенном preview выполните из корня репозитория:

```powershell
node codex/v3/check_povod_clear.mjs --url http://127.0.0.1:4174/ --browser msedge --output "$env:TEMP\povod-clear-qa" --playwright-module "<путь-к-playwright>"
```

Вместо `--playwright-module` можно задать `PLAYWRIGHT_MODULE_PATH`; если пакет разрешается как `playwright`, оба параметра не нужны. Скрипт также поддерживает `--browser chrome` и `--browser chromium` при наличии соответствующего браузера. Список параметров: `node codex/v3/check_povod_clear.mjs --help`.

Скрипт сохраняет `report.json` и скриншоты в `--output`, проверяет маршруты, форму, фильтр пакетов, доступность содержимого и переполнение на нескольких ширинах. Основная визуальная проверка проводится на 1440x900 и 375x812, включая reduced motion. Скриншоты нужно просмотреть вручную.

`build_artifacts.py` собирает прежнюю статику `povod/`, а не этот Vite-проект. PDF-отчёт из `report/` не пересобран и новый интерфейс v3 не покрывает. Публикация этой версии не выполнялась.
